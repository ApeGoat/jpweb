# JP Website Backend

Spring Boot 3.5 API using Java 21, PostgreSQL, Flyway, session-based admin
authentication, and Cloudflare R2 for gallery objects.

## Run locally

From the repository root, copy `.env.example` to `.env`, fill in the R2 values,
then start PostgreSQL with `docker compose up -d db`. When launched from the
`backend` directory, Spring imports the root `.env`; real environment variables
still take precedence.

```sh
cd backend
mvn spring-boot:run
```

The API defaults to `http://localhost:8080`. The admin login creates an HTTP
session, so clients must retain and resend the `JSESSIONID` cookie.

## Seed the gallery

The original gallery images live in `src/main/resources/seed/gallery`. Seeding is
opt-in and uses the same PostgreSQL and Cloudflare R2 configuration as the API.
Set these values in the root `.env` before running it:

- `DATABASE_URL`, `POSTGRES_USER`, and `POSTGRES_PASSWORD`
- `CLOUDFLARE_R2_ENDPOINT`, `CLOUDFLARE_R2_ACCESS_KEY_ID`, and
  `CLOUDFLARE_R2_SECRET_ACCESS_KEY`
- `CLOUDFLARE_R2_BUCKET` and `CLOUDFLARE_R2_PUBLIC_BASE_URL`

Start the backend with the seed runner enabled. In PowerShell:

```powershell
cd backend
$env:GALLERY_SEED_ENABLED = "true"
mvn spring-boot:run
```

In a POSIX shell:

```sh
cd backend
GALLERY_SEED_ENABLED=true mvn spring-boot:run
```

The application uploads each image under the stable key
`gallery/seed/<filename>`, creates a visible gallery row, and then continues to
serve the API normally. Verify the result at `http://localhost:8080/api/gallery`.

Captions and alt text are initially identical. They are generated by removing
the file extension, numeric ordering prefix, and optimization suffixes such as
`-min`, then converting separators into readable title text. Both fields remain
ordinary database values and can be edited later through the admin API.

The runner is safe to repeat: before uploading, it checks for the deterministic
storage key in `gallery_images`. Existing rows are skipped, so subsequent runs
do not upload or insert duplicates. Disable the runner by omitting the argument
or setting `GALLERY_SEED_ENABLED=false`.
